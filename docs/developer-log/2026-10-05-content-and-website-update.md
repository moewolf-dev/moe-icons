# Website content update — 5 October 2026

The Moeicons website now has a clearer introduction to the project and its
available resources.

## Explore the project

The [About page](https://moeicons.com/about) links to three short guides:
[what Moeicons is](https://moeicons.com/about/what-is-moeicons),
[how to use it](https://moeicons.com/about/how-to-use-moeicons) and
[why its shared icon IDs are useful](https://moeicons.com/about/why-use-moeicons).
They explain the Free and Pro groups, published component package and CLI,
and the current plugin status. Vector groups use SVG; the 3D metal group uses
PNG/WebP bitmaps.

## Documentation and updates

The English and Chinese documentation now includes a developer log. Its group
is at the end of the sidebar and starts collapsed. The public README and the
getting-started and Free/Pro guides also give clearer installation and format
information.

## Company and license information

The footer includes the public GitHub repository, About, Terms and Privacy.
Moeicons is operated by Moewolf LTD, a UK company. The company website is
[moewolf.com](https://moewolf.com), and company enquiries go to
`info@moewolf.com`.

Pro remains a one-time purchase. See the
[Terms of Service](https://moeicons.com/terms),
[Privacy Policy](https://moeicons.com/privacy) and the license shown at checkout
for the applicable details.
