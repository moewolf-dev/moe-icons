# 项目进展 — 2026 年 10 月 5 日

这是 Moe Icons 开发者日志的第一篇。本文汇总当前已公开的内容与仍在进行中的
工作。以下内容均以**已发布**的软件包和线上官网为准，而非工作区代码。

## 当前可用

- **每个样式组 554 个语义化 SVG 图标。** 同一个图标 ID（例如 `ui-search`）
  存在于多个样式组中，项目切换样式时无需改导入名。
- **四个免费样式组：** `moe-outline`、`moe-lite-outline`、`moe-solid` 与
  `moe-colored`。免费使用无需账号或登录。
- **已发布的组件包 `moe-icons@0.0.17`**，支持 React、Vue 以及 Vanilla DOM
  用法。使用 `npm install moe-icons` 安装。
- **已发布的 CLI `@moewolf/moe-icons-cli@0.0.3`**，使用图标资源 `0.0.18`。
  `moeicons install free` 无需账号；Pro 安装需要登录并校验账号授权。生成项目
  已在 Vite React/Vue 与 Next.js App Router / Nuxt SSR 上验证。
- **官网搜索与下载**覆盖全部样式组，提供可直接复制的代码片段与单图标下载。

## 进行中

- **VS Code 插件：** 针对 CLI 生成导出的补全与诊断仍在开发中，尚未发布到
  插件市场。请将其视为预览，不要当作可用安装路径。
- **Figma 插件与更多样式组：** 已列入计划，尚未发布。

- 我们只发布经已发布软件包验证的行为。未验证的前端框架目标仍标注为手动示例。
