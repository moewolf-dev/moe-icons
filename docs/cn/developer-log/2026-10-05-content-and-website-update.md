# 官网内容更新 — 2026 年 10 月 5 日

Moeicons 官网现在提供更清晰的项目介绍和资源使用说明。

## 了解项目

[About 总览](https://moeicons.com/about)提供三个介绍入口：
[什么是 Moeicons](https://moeicons.com/about/what-is-moeicons)、
[如何使用](https://moeicons.com/about/how-to-use-moeicons)、
[统一图标 ID 的价值](https://moeicons.com/about/why-use-moeicons)。
内容说明 Free/Pro 样式组、已发布组件包与 CLI，以及插件当前状态。
矢量样式使用 SVG，3D metal 样式使用 PNG/WebP 位图。

## 文档与更新记录

中英文文档增加了独立的开发者日志分组，位于侧栏最后，默认折叠。
公开 README、快速开始及 Free/Pro 对比文档也整理了安装步骤和资源格式。

## 公司与许可信息

页脚现在包含公开 GitHub 仓库、About、服务条款和隐私政策入口。
Moeicons 由英国公司 Moewolf LTD 运营，公司官网为
[moewolf.com](https://moewolf.com)，公司联系邮箱为
`info@moewolf.com`。

Pro 仍为一次性购买。具体信息请阅读
[服务条款](https://moeicons.com/terms)、
[隐私政策](https://moeicons.com/privacy)，并以结账时显示的许可为准。
